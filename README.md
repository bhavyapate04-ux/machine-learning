# 🏙️ NYC Airbnb Explorer | Data Analysis & Machine Learning

An exploratory data analysis project focused on understanding the New York City Airbnb market through data analysis, visualization, and interactive exploration.

The project explores Airbnb listing information to identify pricing patterns, neighbourhood trends, room-type distributions, and other insights that help understand the NYC short-term rental market.

---

## 📌 Project Overview

The **NYC Airbnb Explorer** project focuses on analyzing Airbnb listing data using Python and data analysis techniques.

The project aims to transform raw Airbnb data into meaningful insights through data exploration, visualization, and price comparisons across different boroughs and neighbourhoods.

## 🎯 Objectives

- Analyze Airbnb listings across New York City.
- Understand pricing patterns across different boroughs.
- Explore room types and neighbourhood distributions.
- Identify areas with higher and lower listing prices.
- Visualize data to discover meaningful trends.
- Develop practical data analysis and machine learning skills.

## ⚙️ Installation & Setup

**Step 1: Clone the repository**

```bash
git clone https://github.com/bhavyapate04-ux/machine-learning.git
```

**Step 2: Navigate to the project folder**

```bash
cd machine-learning
```

**Step 3: Install the required libraries**

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

**Step 4: Launch Jupyter Notebook**

```bash
jupyter notebook
```

**Step 5: Open the notebook**

Open `Machine_learning_1.ipynb` and execute the cells to explore the project.
